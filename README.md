# Big Walk Wiki

A fan-made Big Walk game guide website built with Astro, TypeScript, and Tailwind CSS.

## Routes

- `/` - Home
- `/guide/` - Beginner Guide
- `/multiplayer/` - Multiplayer Guide
- `/puzzle-solutions/` - Puzzle Solutions
- `/map/` - Interactive Map
- `/price/` - Price Guide

## Project Structure

- `素材/` - Original planning and source materials
- `src/content/pages/` - Page content entries
- `src/data/` - SEO, navigation, keywords, source, map, and puzzle data
- `src/layouts/` - Shared page layouts
- `src/pages/` - Astro routes
- `src/styles/` - Global Tailwind CSS styles

## Scripts

- `npm run dev`
- `npm run build`
- `npm run preview`
